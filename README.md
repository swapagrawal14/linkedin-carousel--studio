# 🌷 LinkedIn Carousel Studio

My personal toolkit for making LinkedIn carousels that actually perform: an agent system prompt, my data-backed winning formula, and art style references.
*Edu-made fun 🦷 · Dentistry × AI × Art*

## 📁 What's inside
```
linkedin-carousel--studio/
├── prompts/
│   └── carousel-studio-system-prompt.md   ← topic + art style + n slides → 1:1 slides + PDF + caption
├── playbook/
│   ├── linkedin-winning-formula.md        ← what works for me (with real numbers)
│   └── Swapnil_LinkedIn_Winning_Formula.pdf
└── style-refs/                             ← art style references & examples
```

## ⚡ How to use
1. Open `prompts/carousel-studio-system-prompt.md` and copy everything below the `---` line.
2. Paste it as the **system prompt** in any agent (ChatGPT, Claude, Gemini, Hark…).
3. Attach a style reference from `style-refs/`, or just say "surprise me".
4. Send a command:
   - `Ludwig's angina red flags · pink ink style · 8 slides`
   - `Simon's classification · surprise me · 12 slides · Hinglish`

## 🧠 The formula in one line
Fear hook → textbook vs reality → one idea per slide → save/tag → either/or question. No links in the post, 3 to 5 hashtags, 3 posts a week.
